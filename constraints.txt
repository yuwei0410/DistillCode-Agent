# DistillCode-Agent — pinned transitive dependencies for the sandbox image.
#
# WHY THIS FILE EXISTS
#   Dockerfile.sandbox installs requests' upstream requirements-dev.txt, which
#   puts no bounds at all on the Flask / Werkzeug / httpbin stack (httpbin is
#   only declared as `httpbin~=0.10.0`, i.e. any 0.10.x). plan.md requires
#   reproducible trajectories, so this file freezes the exact set that was
#   measured green inside distillcode/sandbox:requests on 2026-09-28.
#
# HOW IT IS APPLIED
#   `pip install -c constraints.txt -r requirements-dev.txt` inside the image.
#   A constraints file is reference-only: it pins versions, it never adds or
#   forces installation of a package by itself.
#
# REFRESH PROCEDURE (only when intentionally upgrading the target env)
#   1. docker build -f Dockerfile.sandbox -t distillcode/sandbox:requests .
#   2. python src/sandbox/docker_runner.py      # smoke test must stay green
#   3. re-run one httpbin-backed case, then re-freeze this file from
#      `docker exec distillcode-sandbox pip freeze` (drop the `-e` line,
#      drop pip/setuptools, which pip freeze hides anyway).
#
# The editable requests install itself is deliberately absent: its version is
# pinned by the REQUESTS_REF build arg (git tag), not by pip.
